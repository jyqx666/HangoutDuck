# 接线（第一阶段：拴线）

```
                      桌面                                   鸭子身上
┌──────────────────────────────────────┐        ┌──────────────────────────────────┐
│ 可调电源 7.4–8.4 V（限流）             │        │                                  │
│   │ 粗线                              │        │   左腿总线：10 → 11 → 12 → 13 → 14 │
│   ▼                                  │  拴线   │                                  │
│ 舵机驱动板 ──── 总线口 1 ─────────────┼────────┼──▶ 左腿（ID 10–14）               │
│    │       └─── 总线口 2 ─────────────┼────────┼──▶ 右腿（ID 20–24）               │
│    │ USB                             │        │                                  │
│    ▼                                 │  USB   │   IMU（WIT，装在躯干，靠近         │
│ Jetson Nano ◀────────────────────────┼────────┼── 仿真里 imu 的位置）              │
│  (5 V 4 A 独立供电，DC 口)             │        │                                  │
└──────────────────────────────────────┘        └──────────────────────────────────┘
```

要点：

- **舵机电源和 Nano 电源分开**。舵机启动和堵转电流大，不要从 Nano 或 USB 取电。
- 舵机电源线尽量粗、短，驱动板到腿的延长线只走信号 + 电源，两条腿各一路，减少单路电流。
- 电源先**限流**：单舵机测试 2 A，整机站立可放到 8–10 A，出问题时电源先限住。
- 拴线要吊起来或由人托着，别让线的重量拽着机身走。
- 设备名会随插拔顺序变化，建议按 `docs/jetson_nano_setup.md` 配 udev 规则固定成
  `/dev/hduck_servo` 和 `/dev/hduck_imu`。

## 舵机 ID 与关节

| ID | 关节 | ID | 关节 |
|---|---|---|---|
| 10 | left_hip_yaw | 20 | right_hip_yaw |
| 11 | left_hip_roll | 21 | right_hip_roll |
| 12 | left_hip_pitch | 22 | right_hip_pitch |
| 13 | left_knee | 23 | right_knee |
| 14 | left_ankle | 24 | right_ankle |

与 xgoduck 相同（xgoduck 的 30–34 是头颈，本阶段不装）。每个舵机设好 ID 后立刻贴标签。
