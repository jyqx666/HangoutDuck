# 接线（第一阶段：拴线供电，主控在机身上）

```
桌面
└─ 可调电源 7.4–8.0 V（限流）
   └─ 电源开关（= 急停）
      └─ 拴线：只走电源（粗线）
         └─ 鸭子身上
            ├─ 舵机驱动板（电源输入）
            │  ├─ 总线口 1：10 → 11 → 12 → 13 → 14（左腿）
            │  └─ 总线口 2：IMU(200) → 20 → 21 → 22 → 23 → 24（右腿）
            └─ 5 V 降压模块（≥5 A）
               └─ 树莓派 5 ── USB ── 舵机驱动板

电脑 ── Wi-Fi / SSH ── 树莓派 5（运行 hduck）
```

要点：

- **拴线只走电源**（粗线，越短越好），机身上分两路：一路直接给舵机驱动板（舵机电源），一路经
  **5 V 降压模块**给树莓派 5。降压模块输入要覆盖 6–9 V、输出 5 V ≥5 A，输入端并一个大电容（例如 470 µF 以上）。
- **桌面电源的开关就是急停**：关掉它，舵机和树莓派一起断电。平时用回车 / Ctrl-C 停止程序，
  急停才直接断电（可能损坏 SD 卡上的文件）。
- 电源先**限流**：单舵机测试 2 A，整机站立可放到 8–10 A。
- 树莓派欠压会降频甚至重启：舵机动作时用 `vcgencmd get_throttled` 检查，见 `docs/raspberry_pi_setup.md`。
- **头颈舵机（30–34）不装，原来经过头部的总线要重新走**：驱动板的两个总线口各接一条腿（两个口是同一条总线，
  程序里只用一个串口）；驱动板只有一个口时加舵机分线板。IMU 用 ID 200 的总线 IMU 时串在其中一路上
  （协议待供应商确认，驱动还没写）；用 USB IMU 时插树莓派的 USB 口。
- 树莓派、降压模块、驱动板都装在机身上，**计入躯干质量**；尽量装在 xgoduck 放电池和主控板的位置，
  质心才接近仿真模型（称重见 `rl` 分支的 `rl/hangoutduck_rl/sim_params.yaml`）。
- 拴线要吊起来或由人托着，别让线的重量拽着机身走。

## 舵机 ID 与关节

| ID | 关节 | ID | 关节 |
|---|---|---|---|
| 10 | left_hip_yaw | 20 | right_hip_yaw |
| 11 | left_hip_roll | 21 | right_hip_roll |
| 12 | left_hip_pitch | 22 | right_hip_pitch |
| 13 | left_knee | 23 | right_knee |
| 14 | left_ankle | 24 | right_ankle |

与 xgoduck 相同（xgoduck 的 30–34 是头颈，本阶段不装）。每个舵机设好 ID 后立刻贴标签。
