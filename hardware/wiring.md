# 接线（第一阶段：电池和主控都在机身上）

```
鸭子身上
└─ 电池（xgoduck 用 2S 18650：标称 7.4 V，满电 8.4 V；本机型号待确认）
   └─ 保险丝 10–15 A
      └─ 电源开关（= 急停）
         ├─ 舵机驱动板（电源输入）
         │  ├─ 总线口 1：10 → 11 → 12 → 13 → 14（左腿）
         │  └─ 总线口 2：IMU(200) → 20 → 21 → 22 → 23 → 24（右腿）
         └─ 5 V 降压模块（≥5 A）
            └─ 树莓派 5 ── USB ── 舵机驱动板

电脑 ── Wi-Fi / SSH ── 树莓派 5（运行 hduck）
```

要点：

- 电池经保险丝、电源开关后分两路：一路直接给舵机驱动板（舵机电源），一路经 **5 V 降压模块**给树莓派 5。
  降压模块输入要覆盖 6–9 V、输出 5 V ≥5 A，输入端并一个大电容（例如 470 µF 以上）；开关和主电源线按 ≥10 A 选。
- **机身上的电源开关就是急停**：关掉它，舵机和树莓派一起断电。不拴线以后机器人会走开，开关要装在
  走动时也能一把按到的位置。平时用回车 / Ctrl-C 停止程序，急停才直接断电（可能损坏 SD 卡上的文件）。
- **电池电压随电量下降**：满电 8.4 V，用到约 7.0 V（每节 3.5 V）就停下充电，别过放。`hduck state` 能看到
  每个舵机测到的电压；运行中低于 6.5 V 会自动卸力（`hangoutduck/runtime/safety.py`）。仿真目前按 7.4–8.0 V 训练
  （`rl` 分支 `sim_params.yaml` 的 `supply_voltage_v`），满电时舵机比仿真里稍有劲、快没电时偏软；
  电池型号确定后把仿真范围改成实际使用的范围。
- 单舵机测试、长时间吊架调试时，可以用可限流的桌面电源从电池接口供电（7.4–8.0 V，先限流 2 A），省电池也更安全。
- 树莓派欠压会降频甚至重启，电池快没电时更容易发生：舵机动作时用 `vcgencmd get_throttled` 检查，
  见 `docs/raspberry_pi_setup.md`。
- **头颈舵机（30–34）不装，原来经过头部的总线要重新走**：驱动板的两个总线口各接一条腿（两个口是同一条总线，
  程序里只用一个串口）；驱动板只有一个口时加舵机分线板。IMU 用 ID 200 的总线 IMU 时串在其中一路上
  （协议待供应商确认，驱动还没写）；用 USB IMU 时插树莓派的 USB 口。
- 电池、树莓派、降压模块、驱动板都装在机身上，**计入躯干质量**。xgoduck 的机身里本来就装着电池和主控板，
  照它的位置装，质心最接近仿真模型（称重见 `rl` 分支的 `rl/hangoutduck_rl/sim_params.yaml`）。
- 锂电池用平衡充电器充，充电时有人看着、放在防火袋里；长期不用时充到存储电压（每节约 3.8 V）；鼓包就停用。
