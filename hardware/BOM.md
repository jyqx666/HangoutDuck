> 机身上的电池、树莓派、降压模块、驱动板都要计入躯干质量。

## 到货验收

- 驱动板：`hduck scan --all-bauds` 能找到一个 1910；`hduck dump --id 1` 能读出寄存器表。
- IMU：总线 IMU 接上总线后 `hduck scan` 应能看到 ID 200（看得到说明它用飞特协议）；USB IMU 用 `hduck imu --imu-port /dev/ttyUSB1`，平放时重力约 `[0, 0, -1]`，数据频率 ≥100 Hz。
- 树莓派：舵机动作时 `vcgencmd get_throttled` 为 `0x0`（不欠压），电池快没电时也要测一次。
- 电池：整机站立时 `hduck state` 读到的电压比空载低不超过约 0.5 V（压降大说明线太细或电池放电能力不够）。
